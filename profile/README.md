# BlackRoad Forge

Mutation lab. Experimental forks, R&D prototypes, and bleeding-edge builds.

This is where ideas get stress-tested before they enter the core system. Forks get road-tested here. Prototypes get hardened here. If it survives Forge, it ships.

## What Lives Here

- Experimental forks of open-source infrastructure
- Pre-release prototypes before they move to Labs or Core
- Build tooling and compilation experiments
- Performance benchmarks and stress tests
- Architecture proofs-of-concept

## Rules

1. **Nothing ships from Forge directly** — it graduates to the right org
2. **Break things here** — that's the point
3. **Document what you learn** — every experiment gets a README
4. **Clean up after yourself** — archive when done, don't let repos rot
